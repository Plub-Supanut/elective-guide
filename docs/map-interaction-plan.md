# แผนที่: แผนการออกแบบ interaction (ฉบับร่างที่ใช้จริง)

> เป้าหมาย: ทุกการขยับต้อง **สื่อข้อมูล** ไม่ใช่แค่ "ขยับให้ดูสวย"
> อาการเดิมที่ต้องแก้: hover รายการภาคแล้ว "แผ่นลอยขึ้น" = ไม่ได้บอกอะไรผู้ใช้ → รู้สึก pointless

## 1. หลักคิด (3 ข้อ)

1. **hover = เพ่งดู (preview) ไม่ใช่ขยับกล้อง** — กล้องนิ่งเสมอขณะ hover เพราะการขยับกล้องเองทำให้ผู้ใช้หลงทิศ
2. **ทุกสถานะต้องมี "ข้อมูลใหม่" โผล่มา** — hover แล้วได้ตัวเลขจริง (จำนวน · ใกล้สุด · ไกลสุด) ไม่ใช่แค่สีเปลี่ยน
3. **คลิก = ยืนยัน** — เป็นการกระทำที่เปลี่ยนสถานะค้าง (กรองรายการ + เลื่อนไปดู) ต่างจาก hover ที่เป็นแค่การชั่วคราว

## 2. สถานะและพฤติกรรม

| การกระทำ | สิ่งที่เกิดขึ้น | ทำไม |
|---|---|---|
| **ชี้** รายการภาค (หรือชี้ตัวภาคบนแผนที่) | ภาคนั้นเข้มขึ้น + เรืองแสงนุ่ม · ภาคอื่นหรี่ลงเหลือ 14% · หมุดในภาคสว่างเต็ม · ป้ายชื่อภาคเข้มขึ้น · **ป้ายตัวเลขจริงโผล่**: "20 สถาบัน · ใกล้สุด 105 กม. · ไกลสุด 842 กม." · **กล้องไม่ขยับ** | ตอบคำถาม "ภาคนี้มีอะไรบ้าง" ได้ทันทีโดยไม่ต้องคลิก |
| **เลิกชี้** | ทุกอย่างกลับสภาพเดิมใน 0.26 วิ | ไม่ทิ้งร่องรอยสับสน |
| **คลิก** รายการภาค | กรองรายการสถาบันด้านล่าง + เลื่อนไปดู · ตัวกรองถูกกดค้าง → ภาคนั้น **ติดสว่างค้าง** (ไม่ต้อง hover) | เห็นสถานะที่เลือกอยู่ตลอดเวลา — ระบบตอบสนองอย่างตั้งใจ |
| **ชี้/คลิก** ตัวภาคบนแผนที่ | เหมือนรายการภาคทุกประการ | ทางเข้าสองทาง พฤติกรรมเดียวกัน |
| **คลิกวงกลมตัวเลข** (กระจุกหมุด) | ซูมเข้าหาพื้นที่นั้น (k=3.4) → หมุดแยกออกเป็นจุดเดี่ยว กดต่อได้ทันที | แก้ปัญหาหมุด กทม. 50 จุดทับกันจนกดไม่ได้ |
| **คลิกหมุด** | ซูมเข้าหาจุด + การ์ดข้างแผนที่ (มี **ระยะทางขับรถ** + เวลา) | เดิมมีแต่ระยะเส้นตรง |
| **กด Esc / คลิกที่ว่าง** | ปิดการ์ด | ทางออกที่คาดเดาได้ |

## 3. สิ่งที่เขียนจริงรอบนี้

**แผนที่ (ภาพรวม)**
- เลิกวาดเส้นขอบจังหวัดทุกจังหวัด (สาเหตุ "ตาลาย") — ประเทศเป็นรูปทรงเดียวเรียบ + ขอบบางจากเงา 2 ชั้น
- สีภาคแบบ **ทึบผสมล่วงหน้า** (ไม่ใช้ fill-opacity ต่ำ) → ไม่มีรอยต่อจังหวัดให้เห็น
- ตัดเส้นกริด 28px ออกจากกระดาษแผนที่ → เหลือแสงนุ่มจากด้านบน
- ป้ายชื่อภาค: ใช้เส้นขอบขาวรอบตัวอักษรแทนกล่อง · ป้ายภาคกลาง กทม. เลื่อนออกไม่ทับกระจุกหมุด
- **กระจุกหมุด** (จับกลุ่มแบบเพื่อนบ้าน ≤11 หน่วย, ตั้งแต่ 5 แห่งขึ้นไป) → กทม. เหลือวง "22" วงเดียว
- ป้าย "รพ.จุฬาฯ" โผล่เฉพาะตอนซูมเข้า (ตอนซูมออกมีกระจุกบอกจำนวนอยู่แล้ว)

**ระยะทาง**
- เปลี่ยนจาก "ระยะเส้นตรง" เป็น **ระยะทางขับรถ + เวลา** ทุกจุด (การ์ด + รายการ "ใกล้สุด/ไกลสุด")
- ดึงล่วงหน้าด้วย `tools/build-drive-distances.mjs` → `map-drive.js` (เว็บไม่เรียก API ตอนผู้ใช้เปิด)
  - ถ้ามี env `GOOGLE_MAPS_API_KEY` → ใช้ Google Maps Distance Matrix (mode=driving, คิดการจราจร)
  - ถ้าไม่มี → ใช้ OSRM (โครงข่ายถนน OpenStreetMap) และเขียนกำกับไว้บนหน้าจอว่าใช้แหล่งไหน

## 4. ยังไม่ได้ทำ (รอตัดสินใจ)

- ป้ายบอกทาง (leader line) จากป้ายภาค กทม. ไปยังกระจุกหมุด
- เอียง/หมุนแผนที่ตามการลากแบบแผนที่จริง (ตอนนี้แพน/ซูมเท่านั้น)
- ไฮไลต์เส้นทางขับรถจริง (ต้องมี geometry จาก Distance Matrix/OSRM — เพิ่มน้ำหนักไฟล์)
